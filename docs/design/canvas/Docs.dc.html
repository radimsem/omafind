206## 7. GPU backend
207 
208The embedding model runs on the user's machine, so the backend decides
209which machines can run omafind at all. Candidates: CUDA, Vulkan, CPU only.
210 
211### Why we picked Vulkan over CUDA
212CUDA is faster on NVIDIA cards but locks us to one vendor; Vulkan runs
213on AMD, Intel and NVIDIA through the same driver stack Hyprland uses.
214 
215- Omarchy ships Mesa, so Vulkan needs no extra install step
216- CUDA adds a 3 GB toolkit and a proprietary driver requirement
217- Measured gap on the 4070: 1.18x slower per batch, 41 ms vs 35 ms
218 
219Decision: ship Vulkan compute as the default backend. Keep the CPU
220path for machines without a usable GPU. Revisit CUDA if the gap
221grows past 1.5x on the target hardware.
